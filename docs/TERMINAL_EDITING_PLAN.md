# 本地与 SSH 终端交互方案

2026-11-17 · 已在当前工作区实施。主窗口和 VNC 窗口共用终端视图，各会话独立工作。

## 打开与关闭会话

首次打开面板，空白页列出本地终端和已添加的可见 SSH 主机。已有标签时恢复当前标签。「新建终端」按钮展开同一组目标，可用方向键和 Enter 选择。从主机或转发入口打开终端会直接连接目标，首次信任和缺少凭据由对应的 SSH 流程处理。

本地终端从用户主目录启动系统 shell，Unix 使用 PTY，Windows 使用 ConPTY 和系统命令解释器。Bash、Zsh 复用下述命令编辑器，其他 shell 使用原生终端输入。

在提示符、命令已结束或仅有后台作业时，点标签上的 × 直接关闭。在前台命令、全屏程序或运行中的服务终端上点 × 会弹出确认；取消后可继续操作原程序。前台状态来自命令编辑器、终端协议标记、备用屏幕，以及本地 Unix PTY 的前台进程组。对没有命令状态标记的原始 SSH 会话，只能识别备用屏幕等可观察状态。

## 每条命令的布局与折叠

每条命令独占一组。主机名显示在面板左上角。命令块首行显示活动环境和路径，最右侧是「更多操作」按钮。环境名取自当前 shell，支持 Python venv、Conda、显式设置的 pyenv 版本和 Nix shell，默认环境名 `base` 隐藏。第二行以 `$` 引导命令。

```text
(analysis) [ 📁 ~/Downloads ]                      ⋯
$ ls
CUDA-MOEA  DinosaurRun  Solar-System
```

最新命令的输出默认完整展开，使用分屏的滚动条。提交下一条命令后，较早命令的输出超过预览高度时自动进入限高预览。高度按当前分屏中的实际折行计算。手动选择的输出模式优先，之后执行命令时仍保留。滚动到长输出中部时，路径行与命令行透明吸顶，输出从两行下方滚过；滚动进入下一条命令后由下一组接替。全屏程序使用备用屏幕，Vim、btop 等程序退出后恢复命令块视图。

路径后的折叠箭头可收起整条命令，路径行保留一行命令摘要。再次展开时恢复该条命令原先的输出预览状态；运行中的命令在折叠期间继续接收输出。

悬停命令块时显示更多按钮，指针离开 350 毫秒后淡出。移回块内、键盘聚焦按钮或打开菜单时保持显示。悬停或点击按钮打开菜单：

- 「复制命令」复制所属块的命令。草稿复制已输入的文字。
- 「复制输出」复制所属块已保留的纯文本输出，包括折叠的部分。正在运行的命令取打开菜单时的内容。
- 「折叠输出」将输出限高为 18 行和当前分屏高度 46% 中的较小值。按当前宽度换行后的实际高度判断；未超过上限的输出在更多菜单中仅提供复制操作。长输出可在预览内滚动，上下边缘复用 `scroll-fade`，仅在对应方向还有内容时逐渐淡出。「展开输出」恢复完整高度，使用分屏滚动条。折叠运行中的输出后，PTY 继续接收数据，同一折叠状态沿用到命令结束。

每个历史标题保留命令提交时的目录和环境。例如，在 `~/Downloads` 执行 `cd ..` 后，该条命令仍标为 `~/Downloads`，下一个提示符显示 `~`。

历史命令较多或单条输出很长时，历史列表和输出行分层使用虚拟滚动。视区附近预渲染行与 ANSI 样式，远处只保留轻量原文，使快速拖动滚动条时也能立即读到文字。已选文本的节点保留到选区释放，查找和复制使用完整的已保留内容。

每条命令归档最近最多 5,000 个 PTY 物理行。整个分屏保留最近至多 500 个命令块，累计最多 50,000 个逻辑行、200 万个 UTF-16 码元和 65,536 个 ANSI 样式区间；达到总预算时优先移除最旧的历史块，最新命令单独保留。

## 输入时看到什么

完成的命令保留 xterm 单元格的前景色、背景色、粗体、下划线和列间空白。普通 `ls` 按远端 PTY 列宽排列；显式指定单列、长格式或管道时按对应命令显示。

用户输入 `cd Dow` 后，如果当前目录存在 `Downloads/`，光标后以半透明前景色显示 `nloads/`。提示沿用终端字体、字号与字符网格。按键盘右方向键 `→` 接受这段文字，接着可以输入下一级路径。鼠标右键继续打开复制、粘贴等菜单。

行内仅显示一个与已输入前缀精确衔接的候选。候选变化时只替换淡色后缀，已输入文字始终使用正常前景色。复制、查找和终端滚动记录只包含实际终端内容。光标移入行中时收起后缀，仍可通过 Tab 补全光标所在的词。

### 补全与历史共用一套选择操作

| 操作 | 反馈 |
| --- | --- |
| 行尾按 `→` | 有淡色后缀时接受整段；其余情况由 shell 处理方向键。 |
| 按 `Tab` | 在当前词旁打开补全列表，高亮第一项。即使只有一项也可先查看。命令位置列匹配的最近命令与可用命令，`cd` 参数列目录，普通路径参数列文件和目录。 |
| 按 `↑` | 打开历史列表，同时将最近一条匹配记录预览到输入行。空行时列最近命令，有草稿时按打开列表前的前缀筛选。相同命令保留最近一次。 |
| 列表内按 `↑` / `↓` | 补全列表按显示顺序移动高亮；历史记录从上到下由旧到新，默认高亮最下方的最新记录。连续按 `↑` 依次取更早的命令，`↓` 返回较新的命令。历史预览随选中项更新。 |
| 补全列表内继续输入或按 `Tab` / `Shift+Tab` | 输入时更新匹配；Tab 选择后一项，Shift+Tab 选择前一项。 |
| 单击候选或按 `Enter` | 将候选填入并收起列表，焦点回到终端。词级补全只替换当前词，保留同行其他参数；整条历史命令替换输入行。再按 Enter 才执行。 |
| 按 `Esc` | 关闭补全列表并保留已经键入的文字；关闭历史列表时恢复打开前的草稿和光标。从最新历史再按 `↓` 也恢复草稿。 |

补全与历史列表只在有候选时展开。历史列表左边缘与输入文字对齐，按内容收窄，最大约 52 个等宽字符，超长记录显示省略号。列表约六行，可滚动，使用主题强调色标记当前项。没有匹配时，命令行可以继续编辑和提交。目录保留末尾分隔符。

重新连接时从当前远端账户的 shell 历史恢复最近至多 200 条命令。启用历史文件时，Bash 和 Zsh 追加 shell 已接受的记录，应用只在内存中使用这些命令。是否跨会话保存由远端历史配置决定。输出和折叠状态属于本次会话。

切回终端、折叠命令、关闭目录面板及点击面板空白处后，当前可见终端恢复输入。搜索框和认证弹窗打开期间优先接收输入。

## 单击已输入的文字定位光标

例如，准备执行 `git commit -m "文档"` 时发现少了“更新”二字。**单击“文”的左半边，输入光标立即移到“文”前**；键入“更新”后，命令变为 `git commit -m "更新文档"`。单击本身只移动插入点，下一次编辑直接作用于远端 shell 的真实输入行。

- **落点。** 单击字符左半边落在字符前，右半边落在字符后；单击最后一行文字右侧的空白落在行尾。中文、组合重音及 emoji 按完整可见字符取前后边界。点击淡色建议视为点击行尾，接受建议仍用 `→`。
- **换行。** 原生多行输入框负责长命令折行后的点击定位与文本选取，输入法和系统按字符处理光标。
- **与选择文本共存。** 拖动可以选择草稿、已执行的命令及多行输出。着色的文本可以跨颜色边界选择。拖选时与打开右键菜单期间使用同一主题前景、背景和行高，多行选区保持连续，点击「复制」使用右击前的完整文字。点复制或按 Esc 关闭菜单后，后续键入回到命令行。实时终端使用 xterm 原有选区。点击面板空白处后可以继续输入。
- **与候选共存。** 单击输入文字时先收起候选，按实际显示的可编辑文字定位；单击候选行则执行选择。中文输入法正在组词时，按键和指针优先交给输入法，待文字提交后再刷新建议与落点。

## 按关键词保存与调用命令

在可编辑提示符中输入命令后按 ↓，输入行旁打开非模态保存层，焦点进入多选关键词框。可选择已有标签、创建新标签，也可用中英文逗号批量输入。保存或取消后继续编辑原命令。历史、补全或关键词候选已打开时，方向键移动选中项，Esc 收起候选。

在输入行键入关键词时，每个候选只显示命令正文，列表按完全匹配、前缀匹配、包含匹配排序，忽略大小写。列表初次出现时没有选中项，直接按 Enter 执行原输入。↑ / ↓ 主动选择后，Enter 回填选中的命令。点击候选或按 Tab 也可回填，随后再按 Enter 执行。继续编辑会清除先前的选择。终端面板右上角的 BookText 按钮打开命令库，可搜索、编辑命令和关键词，或删除记录。本机各终端共用用户主动保存的条目，Rust 将其作为独立数据文件保存，配置导出不包含命令库。

## 点击当前路径切换目录

当前输入行用面包屑显示远端工作目录，层级之间使用斜杠，例如 `~/Downloads/项目`。点击上级名称直接回到该目录，点击末级名称打开子目录列表。空间不足时保留起点和末级，收起的中间层级可从省略号菜单直接选择。单个末级名称过长时，从中间省略字符，悬停可查看完整路径。切换成功后以 shell 回报的目录更新当前分屏，保留输入草稿和光标。历史命令与运行中命令的路径只读，显示各自执行时的目录。

目录面板对齐按钮左边缘，打开时根据所属分屏的可用空间确定方向和高度。加载、搜索和显示结果使用同一位置。搜索栏与弹层共用外框，固定在顶部，以细分隔线衔接目录列表。列表独立滚动，覆盖式滚动条贴齐弹层侧边；上下缘仅在对应方向还有条目时渐隐。顶部搜索框自动聚焦，首行提供「↑ ..（上一级）」，根目录隐藏该项。使用鼠标或方向键在本层子目录中选择。面板复用 Popover、SearchInput 和 ScrollArea。

1. 单击目录或按 Enter，直接请求本分屏的 shell 切到目标目录。已有半条命令时保留草稿和插入点。
2. shell 回报新工作目录后，当前输入行上方的路径按钮显示新目录，面板关闭，焦点回到终端。手动执行 `cd` 后同样更新。
3. 读取期间显示加载状态；目录为空时仍可返回上一级。无权限或目录已消失时，面板内显示原因并可重新加载。Esc 或点击面板外部关闭面板。

## 实现边界

TerminalView 将 xterm.js 输入送入当前会话的本地或 SSH PTY。屏幕上的一行文字可能是命令、历史输出或全屏程序界面。启动增强的依据应是 shell 行编辑器确认的可编辑状态。[终端视图](../src/features/terminal/terminal-view.tsx) · [Rust 终端会话](../src-tauri/src/terminal.rs)

- 本地启动时读取系统 shell。打开 SSH 交互终端时，在同一连接的独立通道识别 Bash 或 Zsh。会话级提示符钩子提供编辑边界、当前目录和环境。原生文本框处理光标定位、选区和输入法，编辑时向 shell 同步草稿与 UTF-8 字节偏移，提交时交还原生 PTY。目录名作为数据传递给当前 shell 的 cd 内建命令。
- shell 集成标记命令提交、开始输出和重新就绪的边界，Rust 按会话与 PTY 输出顺序传递这些事件。历史视图按边界保存命令及其输出范围，遵守现有滚动缓冲上限。折叠只改变展示范围，实时 PTY 持续消费输出。缺少可靠边界的输出作为普通终端内容显示。
- Rust 按现有会话归属传递编辑状态和请求。候选与点击请求携带会话标识和编辑版本；在请求返回前继续打字、切换分屏或窗口重排时，丢弃失效结果。前端按会话事件展示两行布局、折叠内容和候选；实际插入点与工作目录随会话回报更新。
- 仅在已确认的 shell 提示符上接管按键和单击。密码输入、Vim 等前台程序、未识别的嵌套 shell 以及缺少集成的会话，使用原有 PTY 输入。进入这些状态时清除待选内容；工作目录未知时隐藏目录入口。
- 除用户主动保存的命令外，命令、历史正文和编辑缓冲区仅用于当前会话交互，不写入应用配置、日志或诊断产物。补全枚举和目录浏览只读取候选，选择目录才触发切换。

## 验收场景

在隔离的回环 SSH 主机上分别验证 Bash 与 Zsh。涉及输入法、鼠标和窗口缩放的场景使用原生应用窗口。

| 场景 | 可观察结果 |
| --- | --- |
| 把 `ll` 设为一个已保存命令的关键词，在终端输入 `ll` | 直接按 Enter 执行 `ll`。按 ↓ 选择后按 Enter 只回填保存的命令，再按 Enter 才执行。 |
| 在同一分屏依次执行 `seq 120`、`pwd`，在下一行留一段草稿，再在菜单中折叠第一条输出 | 每组首行显示执行时的路径，第二行以 `$ ` 引导命令；第一条折叠后保留路径、完整命令和限高预览，第二条输出和当前草稿可见。展开恢复第一条的输出。 |
| 按路径后的箭头收起命令，再次展开 | 收起后路径旁显示单行命令摘要。展开后恢复原先的完整或限高输出，草稿保持原样。 |
| 在持续输出期间收起再展开，随后执行 `cd ..` | 输出按顺序归入原命令。新提示符显示父目录，历史标题保留各自提交时的目录。 |
| 分别打开路径按钮与更多菜单 | 点击当前提示符的末级目录弹出目录列表，点击可见上级或省略号菜单中的上级可直接回退，点击历史命令路径保持当前目录和草稿；在更多菜单中折叠或展开所属命令的输出。 |
| 输入 `cd Dow`，先复制输入行，再按 `→` | 复制内容只有已输入部分；按键后 `Downloads/` 成为可编辑文字，尚未执行。 |
| 在带后续参数的命令中按 Tab，选择含空格的文件 | 只替换当前词，路径正确引用，余下参数完整。 |
| 输入 `git ` 后连续按两次 `↑`，再按 Esc | 列表高亮与预览同步切到较早的匹配记录，取消后恢复原草稿与光标。 |
| 在折行命令里点击中文或 emoji 前面，再输入一个字符 | 字符插入预期位置；缩放分屏重试，远端最终收到的行内容与屏幕一致。 |
| 拖选输入行、双击选词、点击上一条命令输出及使用输入法组词 | 可以复制预期选区；历史输出点击不改变草稿，输入法候选可正常确认。 |
| 在两个分屏分别打开不同目录，一个分屏带草稿点击子目录 | 成功后保留该分屏草稿和光标；分别执行 `pwd` 与两个路径按钮逐一核对。 |
| 点击已删除或无权限的目录，或在慢响应期间继续输入 | 错误留在面板内，工作目录准确；迟到候选不覆盖新输入。 |
| 在 Vim、密码提示及不支持的 shell 中操作 | 方向键、Tab 与鼠标交给当前程序；应用历史、配置和日志中无密码输入。 |
