## 新增

- **终端组合面板**。拖放本地或 SSH 终端标签即可分屏。可以把新会话放到单块面板旁，也可以沿整组外缘新增一行或一栏。拖动分隔条可调整比例，重排或拖回独立标签时保留原会话、输入草稿和历史输出。关闭组合前会列出将结束的会话。

## 优化

- 减少拖动终端面板边缘、分屏分隔条和调整窗口大小时的卡顿。
- 改善大目录和长传输队列在滚动、缩放时的响应速度，保留已展开的批次明细和键盘焦点。
- 加快大型文件批次的续传，减少跳过已完成文件时的进度刷新。核验传输结果期间仍可打开其他文件会话。
- 应用内更新说明支持 Markdown 标题、列表和链接。

## 修复

- 修复 macOS 应用内更新后重启可能出现重复 Dock 图标的问题。
- 修复 Windows 图标缓存不可写时，主窗口和任务栏图标可能无法更新的问题。损坏或不可写的快捷方式也不会再触发应用图标更新失败的提示。
- 修复本地 Zsh 启动或按 Ctrl+C 后，终端记录可能多出反色行尾标记的问题。
- 修复 SSH 配置中的嵌套 `Include` 或通配符引入可能错误继承 `Host`、`Match` 条件的问题。
- 修复文件传输恢复时可能丢失暂停、待处理冲突或失败原因的问题，并改进旧批次记录的续传。队列会保留仍需核验传输结果或清理临时文件的记录。
- 修复 Windows 选择仅大小写不同的远端文件时可能漏选的问题。下载到本机遇到重名时统一走冲突处理，避免覆盖已有文件。
- 修复 SFTP 会话建立过程中，打开通道和协商协议可能未及时响应超时或取消的问题。
