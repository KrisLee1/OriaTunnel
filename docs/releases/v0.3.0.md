## 更新日志

- 新增内置 VNC 远程桌面。从 VNC 转发或 `vnc://` 链接打开独立窗口，可全屏、缩放、发送 Ctrl+Alt+Del。也可选择系统默认 VNC 客户端。
- 支持双向剪贴板文本传输，可将本机文本粘贴到远程桌面，也可把远端复制的文本取回本机。
- 在远程桌面窗口中打开 SSH 终端和文件传输面板，使用已添加主机的凭据。关闭桌面窗口后，后台文件传输可继续完成。
- 改善 4K 和单屏 6K 桌面的滚动、拖动和刷新，修复 Windows 非整数缩放时重复的像素行列。支持使用经典 VNC 密码连接 Mac 屏幕共享。
- SSH 终端和 SFTP 会指出需要认证的主机或跳板，密码错误时可直接重试。删除仍在使用的主机时，可取消或选择停止相关服务后删除。
- 主机页和转发页可分别撤销本次运行中最近 20 次删除。撤销主机删除会一并恢复其关联转发，恢复的转发保持停止。
