## 新增

- **终端组合面板**：拖放本地或 SSH 终端标签即可分屏，支持按行或列排列、调整比例和重排，并保留会话、输入草稿与历史输出。
- **Windows SSH 智能终端**：远程 PowerShell 支持命令补全、历史记录和盘符切换。
- **文件时间排序与分组**：文件可按创建时间排序、按日期分组，传输记录可按提交时间分组。

## 优化

- **终端与文件面板**：减少拖动分屏、调整面板大小和滚动长列表时的卡顿。
- **大目录传输**：可直接选择整个文件夹传输。准备时显示扫描进度，传输时显示速率、已用时间和更稳定的剩余时间估算。
- **传输恢复**：暂停、断线或退出后，点击「继续」可按需重新连接，复用有效的目录扫描结果，并跳过已完成的文件。
- **界面提示**：改善搜索无结果和空列表的提示，应用内更新说明支持 Markdown。

## 修复

- **SFTP 兼容性**：修复部分 Windows OpenSSH 服务上的目录读取和下载失败，以及连接时未及时响应超时或取消的问题。
- **文件名冲突**：修复仅大小写不同的远端文件可能漏选的问题，下载到本机时的重名文件会进入冲突处理。
- **传输队列**：修复重启后可能丢失暂停状态、待处理冲突或失败原因的问题。
- **SSH 配置发现**：修复通过嵌套 `Include` 或通配符引入配置时，可能错误继承 `Host`、`Match` 条件的问题。
- **应用图标**：修复 macOS 更新后重启可能出现重复 Dock 图标，以及 Windows 切换应用图标时可能误报失败的问题。
- **本地 Zsh**：修复启动或按 `Ctrl+C` 后可能出现多余行尾标记的问题。
