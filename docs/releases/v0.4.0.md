## 更新日志

- **命令补全**。在 Bash、Zsh 或 Windows 本地 PowerShell 中输入命令时，按 → 接受行尾建议，按 Tab 查看补全候选，按 ↑ 找回历史命令。
- **目录切换**。点击当前路径中的上级目录即可返回，点击末级目录可选择子目录。Windows 本地终端还能通过「此电脑」切换盘符。切换后可继续编辑原来的命令草稿。
- **命令库**。按 ↓ 为常用命令添加关键词并保存。在其他会话输入关键词即可找回，选中后回填到输入行，核对后再执行。
- **多行输入**。按 Shift+Enter 换行，在同一处编辑整段命令，完成后按 Enter 执行。
- **长输出折叠**。当前命令的输出默认展开。执行下一条命令后，上一条的长输出收为可滚动预览，可随时展开，也可从命令菜单复制已保留的输出。
- **交互优化**。从终端面板即可新建本地或 SSH 会话。关闭仍在运行前台命令的标签时会提示确认。拖放文件时可看到选中数量和目标目录高亮。
