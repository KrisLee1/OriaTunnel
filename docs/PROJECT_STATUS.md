## Windows 记住密码（2026-10-23）

- 用户已确认安全方案并授权实施：认证弹窗默认不记住密码，只有实际 SSH 密码认证成功后才写入当前用户 Windows 凭据管理器；私钥口令不保存。目标、跳板、主机测试和批量启动共用认证输入与按主机同意，保存密码只由 Rust 读取，前端仅收到保存状态/错误且不会回填密码。
- 凭据按应用配置路径及稳定主机 ID 隔离，另绑定地址、端口、用户名和认证方式；绑定不匹配时不复用并清除旧条目。认证输入留空可复用，明确输入及同意才在成功后替换。支持清除，清除代次阻止正在连接或重连中的旧保存请求写回；运行代次和最新主机身份也必须仍匹配。保存失败独立反馈，不把已成功认证改成连接失败；凭据损坏时提供清除入口。
- 密码不进入配置、日志、导出或前端持久化。已保存密码不用于私钥解密，不改变启动自动连接的指纹与密钥/系统代理要求；清除只影响保存值，现有会话及其重连内存不受影响。其他平台暂不提供保存能力。

## B 当前实现与证据

- 新建转发始终打开独立编辑器，L/R/D 使用不同字段、示例与 DNS/localhost 访问侧说明。无主机时可就地添加或管理主机，保留草稿；仅添加主机不生成规则。支持保存、保存并启动、编辑、复制、删除；网络修改明确中断后重新认证。名称与后台偏好不重连。
- Rust 实现真实 L direct-tcpip、R 远程监听/取消和 D SOCKS5 TCP CONNECT。发送/接收统一以此电脑为参照，R 已用非对称请求/响应校验。D 仅回环、无 SOCKS 认证/UDP；域名原样交给 SSH 服务端。R 的目标由本机访问；非回环监听显示服务端策略与防火墙限制，不承诺公网可达。
- 主机与规则支持连接与初始握手超时（核对指纹时暂停计时）、SSH 保活间隔（0 关闭）、保活未响应次数；规则默认 -N，可明确启用无交互远程命令，输出不记录。每条规则可独立决定收起窗口后是否继续运行。
- 主机管理支持手动编辑、认证方式、候选私钥、标签、隐藏/恢复、配置主机复制为手动、来源字段定位与源转发信息。配置主机可单独保存应用显示名/标签，连接字段只读。直接或经跳板被规则引用的主机不能删除。
- 用户主动点击「测试连接／保存并测试」后才执行 SSH 身份和主机校验；不创建监听或执行远程命令。扫描、启动应用、自动同步均不会自动连接。
- Windows OpenSSH Agent 命名管道与 IdentityAgent、IdentitiesOnly 已实现；基础 ProxyJump 使用已保存主机或具体 Host 别名，每跳单独认证与信任，拒绝缺失、诊断和循环路线。尚不支持内联 user@host:port、逗号路线、ProxyCommand；不启用 Agent forwarding。
- 配置每 2 秒及恢复焦点时检查；设置可增加来源文件、关闭自动检测，手动刷新及启动加载保留。检测是文本扫描，不执行配置命令。源更新保留本次运行快照；删除/改名保留规则与最后成功快照，读取失败保留旧候选并阻止错误连接。旧配置迁移后运行态为空。
- 托盘提供恢复窗口、停止全部、退出。关闭默认收起；未允许后台的规则及主机测试在收起时取消。退出始终等待会话清理，重复退出请求不会绕过清理。每用户应用目录内的系统文件锁确保单实例，本机 IPC 只支持唤起窗口；异常退出后锁由系统释放。
- 运行代次过滤旧回调。画布按类型安排 L 右、R 左、D 右下，R 边反向；保存聚焦规则，布局与视口继续持久化；卡片编辑按钮及边打开同一编辑器。
- `pnpm test` 39 项、`pnpm build`、严格 Clippy 通过；Rust 全套为 11 项单元测试、8 项隔离 SSH 集成测试通过。覆盖三种真实加密转发、256 KiB 数据/半关闭/字节数、SOCKS 远端域名与 IPv6、协议错误、R 端口占用/策略拒绝、密码/加密私钥/错误口令/指纹、逐跳验证与取消、Windows 专用测试管道 Agent、主机测试无监听/无命令、配置失效、后台生命周期、握手超时回收及人工核对指纹期间暂停计时。
- 原生隔离窗口已核对空主机「新建转发」与嵌套添加主机：草稿名保留并自动选中新主机，磁盘为 1 主机、0 规则。关闭后进程继续驻留；二次启动退出码 0、仅原进程存在且恢复同一窗口。验证数据位于忽略目录 outputs/b-native，未向真实 SSH 配置写入测试条目或连接真实主机。
- 正常构建 `cargo build --manifest-path src-tauri/Cargo.toml --offline` 通过；最终应用已使用正常数据目录启动，画布显示 0 条规则、0 个运行会话，保留原视口偏好。空规则的隔离验证进程已清理，测试私钥临时文件为 0；没有创建提交、推送或发布。
- 本轮保留 JSON 临时文件替换存储；未接入凭据库、自动重连、自启动或持续日志。macOS/Unix Agent 与跳板尚无设备验证，不把 Windows 测试作为跨平台证据。构建仍有主包体积提示；测试缓存偶有硬链接回退提示。
